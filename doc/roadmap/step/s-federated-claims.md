Project A concludes something. Project B, on the same hub, uses that conclusion as a premise by linking to A's page, not by copying it. The hub now knows the dependency. If A's conclusion is weakened or retracted after a review cycle, B's premise is flagged automatically, along with everything built on it.

Across many projects and labs this becomes a network in which claims point at claims, each with its own status and version. Papers cite whole papers; this tracks which specific claim depends on which, and spreads doubt when one breaks.

This needs identifiers that do not move when a project is renamed or edited: [[s-stable-ids]].
