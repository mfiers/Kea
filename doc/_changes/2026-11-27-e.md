## Changed

- `propose`: a proposal for a new page (brief, experiment, question, premise, hypothesis, step, control, conclusion, caveat, alternative hypothesis or explanation, method change, option), as the site's Propose: a thread with that proposal tag on a page of the right type; the agent takes it into the plan at the harvest and writes the page at Implement. A wrong page type is refused with pages where it can go.
- `get_plan`: the cycle's state and the plan (current or an earlier cycle), and how many comments are open.
- `comment` takes page "plan": a comment on the current plan.
- `start_harvest` and `start_implementation` (PI or director): Harvest and Implement as on the site, each with a read-back first and confirmed=true after a yes; refused when the cycle is not in a state that allows it.
- Pages are never written by the hub: everything goes through the review cycle as on the site.

Hub: upgrade needed (the MCP tools live in the hub). Sites need no rebuild.
