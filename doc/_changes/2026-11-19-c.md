## Changed

- The menu's foot has two rows. "This site v0.2.0" is the version of the project's content: its pages, results and conclusions, one per release. The hover explains MAJOR, MINOR and PATCH. Below it in small type, "Kea 1.31.4 · hub 1.31.4" (or "server" under `kea serve`): the Kea that built the site and the one the hub runs. The hub version is red only when MAJOR.MINOR differ; the hover says why.
- CLAUDE.md, a new section, "Kea's own version numbers": the page scripts travel inside every built site, so the hub's Kea only serves the API. A change that needs the hub or `kea serve` to be upgraded before a new site works is at least a minor release, and each change entry says whether the hub must be upgraded.

Hub: no upgrade needed (page scripts only).
