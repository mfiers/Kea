## Asked

Mark Fiers, 10 November 2026 (in chat and through the keahub session): the hub's help header ("How to read a Kea site" / "The same text as every site's Help page…") makes no sense. Start with the heading "What is Kea?" and this tagline, verbatim, and use it everywhere Kea describes itself: "Break a data analysis into small, linked nodes: questions, hypotheses, steps, results, conclusions. You and your AI agent work through them one at a time, reviewing each before moving on."

## Changed

- The tagline is one constant (`kea.TAGLINE`), used by the hub's front page (under the title and in the footer), `kea --help`, the PDF's closing line and the web page's description; `pyproject.toml` and the GitHub description carry the same words.
- The shared help opens with "What is Kea?", the tagline and one paragraph on how the agent and the readers work; so do every site's Help page, the hub's front page and /help, README.md and the GitHub page. README's own opening paragraphs, which said the same with the old tagline, are gone.
- The hub's help section and /help lost their extra heading and explanatory line; a line of section links ends the help.

## Checked

`pytest` (109 tests; the help test now checks that the help opens with the tagline and that pyproject carries it). The hub's front page and /help looked at in screenshots.
