## Asked

Mark Fiers, 18 November 2026, after the reassessment of the buttons and the flow (run 2026-11-18-c): implement as proposed: sign-offs that do not wait for a harvest, one main button per stage ("Approve & continue" with "Approve only" beside it), fewer buttons on the page, and no "harvest" in the wording of sign-offs.

## Found

- Approve on the site woke nobody: the sign-off waited for a PI to press Harvest, so a biologist who approved and left found nothing moved.
- "Approve all N" signed the stage but started nothing; "▶ Approve & run the step" started work but signed one page: no single click signed a stage and continued.
- Ten buttons on a waiting page (Comment, Edit, Approve all, This page only, Approve & go, Revise, Drop, Propose, Next run, Manuscript).

## Changed

- `kea watch` exit 50: an open Approve on the site, or a Revise or Drop on a page that waits (the site adds the hidden tag `route`), stops the watcher at once. `kea sign --pending` writes every open site sign-off onto its pages (bound to the version seen) and lists the Revise and Drop requests; the agent commits, builds, publishes, answers each thread (`--status answered`) and starts nothing else. Sign-offs and route decisions no longer count as comments for the harvest.
- One main button per stage on a page that waits: "▶ Approve all 3 & run the plan" (or & write the plan, & draw conclusions, …) signs every page of the stage and asks for the stage's next step (`graph.stage_action`: two or more planned steps → run the plan; results without conclusions → draw conclusions; else the page's own step). Beside it "✓ Approve only", which on a stage opens a choice: all N pages, or this page only. Approve is the green main button where there is no next step to ask for.
- The page buttons: Comment · ▶ Approve & … · ✓ Approve only · Change ▸ (Edit, Revise, Drop) · More ▸ (Propose, Next run, Manuscript); the groups open in place and their heads show what is asked ("Change · drop asked", "More · 2").
- Wording: a sign-off says "Claude writes it on" / "when Claude picks it up", never "at the next harvest". The Progress page's button column names the stage's button.
- Approve & go instructions: also apply other open sign-offs (`kea sign --pending`); "run the plan" runs every approved planned step of the question, then its results.
- Skill (approval, watch exits renumbered with exit 50), CLAUDE.md template, help (reviewing, progress), README.
