## Asked

Mark Fiers, 10 November 2026: revamp the hub's front page (the bird aligned to the top of the text, the help readable without an account, links to GitHub), and make Kea's documentation on GitHub a verbatim copy of the help on the Kea sites, which self-contained sites and PDFs keep including.

Later the same day, from Mark's notes on related work and vocabulary (agreed in chat: all proposals except the RO-Crate export, which waits; a related-work page; "what Kea adds" stated): a new tagline, Toulmin and GRADE named, `fixed_before_results` kept and not called preregistration.

## Changed

- The reader's help is one set of Markdown files in `src/kea/help/` (why Kea, why small pages, how a project progresses, reading a site, comments and the review cycle). They are shown verbatim on every site's Help page, on the hub's front page and at `/help`, in the PDF's "About this document" (why and how a project progresses), and in README.md between `<!-- help:… -->` markers; `make web` copies them into README.md and builds the GitHub page from it. A test fails when README.md is out of date.
- The site's Help page renders those files, with the route drawn in the site's tags and the coloured page types; the comments part only on sites served with comments.
- The hub's front page: the kea head aligned with the top of the title; Help and GitHub links in the bar, under the sign-in and in the footer; the help below the public projects, with a contents line. `/help` shows the help alone, for visitors and signed-in readers.
- New tagline, in README.md, the web page and the GitHub description: "Structure a data analysis as small, linked blocks (questions, hypotheses, steps, results, conclusions) and run your AI agent on them, one reviewed step at a time."
- Help: a section "What Kea adds" (approval at each step, hypotheses fixed before the test, rechecks downstream, versions of the whole graph, all in git), stated as what we found in the systems surveyed, not as a claim that nothing like it exists; the reason on a link is named as Toulmin's warrant and the certainty as GRADE's four labels (without GRADE's method); fixing a hypothesis in git is said not to be a public preregistration.
- A related-work page (`doc/_site/related-work.md`, on Kea's site and as docs/related-work.html): micropublications, discourse graphs, Octopus, nanopublications, SEPIO, Toulmin, IBIS, GRADE, PROV-O, Workflow Run RO-Crate, CiTO, Kosmos and POPPER, a table mapping Kea's terms onto theirs, and the sources. Citations were checked against their primary sources, except Toulmin 1958 and Peroni & Shotton 2012 (cited from memory) and the full text of the 2008 GRADE paper (not accessible); corrected from the notes: Octopus's type names, discourse graphs as a Roam extension (Obsidian only by hand), Kosmos names no relation types, SEPIO has no "information item", the Octopus results/analysis remark is one interview, not a finding.
- `make web` also builds a web page for each `doc/_site/*.md`.
