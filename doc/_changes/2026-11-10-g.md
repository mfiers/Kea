## Asked

Mark Fiers, 10 November 2026: an experiment should never have files linked to it directly, and the graph check should prevent it; under an experiment, a "Questions" section with only the questions, and a section with the experiment's state like "Answer so far"; a clear way to see who commented what, under Plan; build and upload take long after an implementation round, even for small projects; Esc closes the comment window.

## Changed

- Graph rule (`kea check`, the strict build): an artefact or figure under the experiment or linked to it, and `sources:` or `from_artefact:` on an experiment page, are problems; they belong under the step that made them or the result that uses them. The experiment page has no "Figures and files" section.
- The experiment page, after its text: "Questions" (one line per question: tag, title, status) and "Answers so far" (each question's answer and its conclusions, taken out of About this page), each under its own separator.
- Plan → Current comments (`comments.html`): one table of who commented what, on which page and in which state, newest first, with a filter per person and current or all comments. Served on a hub or with `kea serve` it shows the live list; a static copy shows the comments known at the build.
- Builds: the change-log pages no longer resolve every page's path for every changed file; git output for fixed commits is kept in `report/.cache/git/` (which ignores itself in git); a page's version and "Changes to this page" come from one `git log` for the whole repository instead of three git processes per page, with `git log --follow` asked only for what lies before a page was added (cached); front matter is read with libyaml when PyYAML has it. The s100 site (491 pages) builds in about 12 s instead of about 100 s (44 s while the cache fills), with byte-identical output.
- Publishes: pages no longer carry the build's id (cycle.js takes it from the server at the first poll; older pages keep working), so a page's bytes change only when its content does and a publish sends only those pages. Text goes up gzip-compressed when the hub says it accepts it (hubs from 1.26; older hubs get plain chunks); the hub refuses a chunk that would decompress beyond its chunk limit.
- Esc closes the comment window, after closing the selection bar or the dock's menu first; editing a title or summary in place keeps Esc for itself.
- Help, skill and README describe the experiment page, the rule and Current comments.
