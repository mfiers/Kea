## Found

Not broken: that is the banner of a waiting Approve & go request (the request was saved and waits for the agent). Since 1.30.0 a stage's Approve & go carries a `Signs:` line (page keys and versions, for `kea sign`); the banner, the Progress page's request table, the page's ▶ button while the request waits and the watcher's "doing" line showed the thread's whole text, that line included.

## Changed

Readers see what was asked, "Approve all 4 & run the plan" (the number of pages counted from the `Signs:` line, which is never shown), in the banner, on Progress and on the page's button; the watcher's status line uses the first line only.
