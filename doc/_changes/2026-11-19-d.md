## Asked

Mark Fiers, 19 November 2026: when looking at page changes, the commits are large and say little about a given page. Add a diff to the page (a tab, About this page, Changes) showing exactly what changed on it in a round.

## Changed

- The Changes tab of every page lists one line per release (or "not released yet") as before. Each line now has "What changed on this page in vX.Y.Z" (or "since the last release"), which folds open: the page's text from before its first commit in that round to after its last, for this page alone. Only changed lines are shown, so a paragraph or a front-matter field (`criterion: …`) is one line. Words taken out are struck through on red and words put in underlined on green; "…" marks a jump between changes. The newest round is open. A page created in the round says so instead.
- Code pages get the same diff under their history.
- Help (Reading the site) describes it.

Hub: no upgrade needed (built into the static pages).
