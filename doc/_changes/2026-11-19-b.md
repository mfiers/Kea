## Asked

Mark Fiers, 19 November 2026, on Progress: Review and Harvest are intermixed (people go on commenting after a harvest), so mark Harvest only when no comments wait, or warn; drop the "Now: the plan is ready …" box; in "Needs your sign-off" say "Experiment" for an experiment, put the tag (C1) in front, give every button a hover with more information, and make tag and title one link. On a question page: what is "Keep as is · waits for Harvest"? The harvest state is weird: I can comment, but there is no re-harvest. In a comment field: Ctrl/Cmd+Enter to send, Esc to cancel.

## Changed

- Progress, the four steps: after a harvest, a comment or sign-off puts the round back in Review ("again: N comments since the plan"), and Harvest is marked "plan out of date" (dashed amber), with a hover that says what to do. Harvest shows "done: plan ready" only when nothing came in since.
- The "Now: …" box is gone; the line on Claude's session stays.
- Menu bar, harvested state: for a PI, "⇣ Harvest again · N" when comments came in after the plan, with ▶ Implement beside it (which then leaves those comments for the next round, as its confirmation says). The server already allowed a second harvest; only the button was missing.
- "Needs your sign-off" (and the other tables on Progress): the tag first, then the title, as one link; a page without a tag shows its kind ("Experiment"). The hover names number, title, summary, kind and status. The steps, the counts, the state pills, the start link and the Next-step cells have hovers that explain them.
- A settled page (signed, or one that never waited) has no green button any more: "Keep as is" (the old Confirm) was an extra stamp on a page that already shows its sign-off. An old confirmation request still shows so it can be taken back; `confirm` threads are still applied.
- Comment, reply and proposal fields: Ctrl+Enter (⌘+Enter) sends; Esc presses Cancel, or clears the field where there is no Cancel.

On Q1 (settled) no green button shows; "Next to sign (4) →" does. Ctrl+Enter in the page's comment box posted the comment and emptied the field; Esc cleared a draft.
